# mailer-docs

Fumadocs documentation site for
[Mailer](https://github.com/ASHUTOSH-SWAIN-GIT/mailer).

Run development server:

```bash
npm run dev
```

Open http://localhost:3000 with your browser to see the result.

## Content

Docs live in `content/docs`.

Useful commands:

```bash
npm run types:check
npm run build
```
