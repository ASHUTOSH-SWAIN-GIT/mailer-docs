Weibo records metrics during execution and exposes pipeline descriptions for a
dashboard.

## Stage and edge metrics

| Metric | Meaning |
| --- | --- |
| `weibo_edge_queue_size` | Current queue depth for a bounded edge. |
| `weibo_edge_queue_capacity` | Configured edge capacity. |
| `weibo_stage_records_in_total` | Records entering each stage. |
| `weibo_stage_records_out_total` | Records leaving each stage. |
| `weibo_stage_send_block_seconds_total` | Time blocked by downstream backpressure. |
| `weibo_stage_workers` | Worker count for stage. |
| `weibo_stage_errors_total` | Stage errors. |

## Operator labels

SDK labels and workflow operator ids are used in descriptions and dashboard
metadata.

```go
stream.Filter(isCompleted, "completed")
```

```yaml
- id: completed
  type: filter
```

## Secret hygiene

Pipeline descriptions and dashboard metadata must not include resolved secret
values. Workflow compilation keeps sensitive values out of graph descriptions.
